# ประเภทพนักงาน (EmployeeType)

## WORKER — พนักงานรายวัน

- จ่ายเป็น **รายวัน**: จำนวนวัน × dailyRate — วันลา/วันหยุดนักขัตฤกษ์ **นับเป็นวันทำงาน** เต็มวัน
- มีรอบจ่าย **24 รอบ/ปี** (ครึ่งเดือน)
- ใช้ TimeSheet แบบ **DAILY** (ลงเวลาทีละวัน ต่อ workLeader)
- คิดเงิน "ต่อวัน": นาทีทำงานจริง + นาทีลา → ≥480 = dailyRate / <480 = ย่อยหน่วยรายชม.
- Holiday pay: ทุกวันนักขัตฤกษ์ได้ dailyRate อัตโนมัติ (มาทำต้องลง holiday_2x/3x — ได้ซ้อนอีกชั้น)

## DRIVER — พนักงานขับรถ

- จ่ายเป็น **รายเดือน**: `monthlyRate − absenceDeduction` (หักขาดรายชั่วโมงแบบย่อยหน่วย)
- มีรอบจ่าย **12 รอบ/ปี** (รายเดือน — เดือนเต็ม วันที่ 1–สิ้นเดือน)
- ใช้ TimeSheet แบบ **MONTHLY** (ลงเวลารวมทั้งเดือน ต่อ employee)
- วันที่มีชั่วโมงคาดหวัง = **จันทร์–เสาร์** (อาทิตย์/นักขัตฤกษ์/วันลา = ไม่มี)
- REGULAR entry ไม่ผลต่อเงินโดยตรง — ใช้แค่นับ "ชั่วโมงทำจริง" ของวัน
- **เข้าใหม่กลางเดือน** (startDate อยู่ในรอบ) → สลับเป็นจ่ายรายวัน: วันสุทธิ × dailyRate
- ได้ payroll ทุกรอบแม้ไม่มี entry เลย (ไม่มาทั้งเดือน = ขาดทั้งรอบ โดนหักจน clamp 0)

## ความแตกต่าง

| | WORKER | DRIVER |
|---|---|---|
| รอบจ่าย | 24 รอบ/ปี (ครึ่งเดือน) | 12 รอบ/ปี (เดือนเต็ม) |
| TimeSheet | DAILY (ต่อ workLeader) | MONTHLY (ต่อ employee) |
| Lunch break (12:00–13:00) | มี (shiftType REGULAR) | **มีเหมือนกัน** — ใช้ `effectiveMinutes` ร่วมกัน |
| ค่าจ้างหลัก | วัน × dailyRate | monthlyRate − หักขาดย่อยหน่วย |
| OT | สูตรเดิม + pattern holiday_2x/3x วันหยุด | สูตรเดิม แต่**นอก 08:00–17:00 จ–ส เท่านั้น** |
| วันลา | ได้ค่าจ้าง (เติมนาที/จ่ายที่สรุปยอด) | ไม่นับขาด |
| วันหยุดนักขัตฤกษ์ | +dailyRate อัตโนมัติ | ไม่นับขาด (เงินเดือนครอบอยู่) |
| ค่าที่พัก | ไม่รองรับโดยตรง | รองรับ (ACCOMMODATION) |
| netPay ติดลบ | ได้ (ตาม deduction) | **clamp ที่ 0** |
